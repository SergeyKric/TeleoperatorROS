Лабораторная работа №1
Тема: Работа с системой контроля версий Git при командной разработке.

Тема ВКР:
«Программный модуль информационного обмена тренажёра «Телеоператор РОС» с АИС ТСПК на основе Apache Kafka».

Содержимое папки:
- src/main.cpp — точка входа учебного проекта;
- src/DataProducer.cpp — учебный компонент Kafka Producer;
- src/DataConsumer.cpp — учебный компонент Kafka Consumer;
- config/kafka_config.txt — итоговая конфигурация Kafka после разрешения конфликта;
- README.md — описание проекта и упрощённая архитектура;
- .git — история Git с ветками и коммитами для демонстрации лабораторной работы.

Упрощённая архитектура:
Тренажёр «Телеоператор РОС» -> программный модуль -> Kafka Producer -> Apache Kafka -> Kafka Consumer -> АИС ТСПК.

Полезные команды для демонстрации:
1. git status
2. git branch -a
3. git log --graph --oneline --all --decorate
4. git show feature/data-producer
5. git show feature/ais-integration
6. git show feature/config-update
7. git show feature/consumer-config

Примечание: исторические названия веток сохранены, так как они являются частью демонстрации Git. В текущей версии компоненты отправки и получения данных трактуются как Kafka Producer и Kafka Consumer.

Текущая ветка: main.

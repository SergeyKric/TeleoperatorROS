# Программный модуль информационного обмена тренажёра «Телеоператор РОС» с АИС ТСПК

Учебный проект для лабораторной работы №1 по теме работы с системой контроля версий Git.

Проект моделирует разработку программного модуля информационного обмена между тренажёром «Телеоператор РОС» и АИС ТСПК.

Основные компоненты:
- модуль отправки данных;
- модуль получения данных;
- конфигурация соединения;
- демонстрация ветвления, коммитов, слияния и разрешения конфликтов в Git.

# Программный модуль информационного обмена тренажёра «Телеоператор РОС» с АИС ТСПК на основе Apache Kafka

Учебный проект для лабораторной работы №1 по теме работы с системой контроля версий Git.

Проект моделирует разработку программного модуля информационного обмена между тренажёром «Телеоператор РОС» и АИС ТСПК с использованием Apache Kafka в качестве брокера сообщений.

Основные компоненты:
- Kafka Producer для отправки сообщений тренажёра в Kafka-topic;
- Kafka Consumer для получения сообщений со стороны АИС ТСПК;
- конфигурация Kafka-брокера и topic;
- демонстрация ветвления, коммитов, слияния и разрешения конфликтов в Git.

Упрощённая архитектура:
Тренажёр «Телеоператор РОС» → программный модуль → Kafka Producer → Apache Kafka → Kafka Consumer → АИС ТСПК.
